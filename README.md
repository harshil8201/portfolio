# Portfolio

Personal portfolio of Harshil Patel, live at **https://harshil8201.github.io/portfolio/**.

Built with React, Vite and Tailwind CSS, and deployed to GitHub Pages.

## Edit the content

All text (profile, experience, skills, projects, education) lives in one file:

```
src/data/profile.js
```

Layout components are in `src/components/`. Colours and fonts are in `tailwind.config.cjs`.
To change the photo, replace `src/assets/profile/profile.jpg` (square, about 640 × 640 px).

## Commands

```bash
npm install      # first time only
npm run dev      # local preview at http://localhost:5173/portfolio/
npm run deploy   # build and publish to GitHub Pages
```
